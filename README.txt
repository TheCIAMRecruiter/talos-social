TALOS SOCIAL — VERCEL WEBSITE PREVIEW

This package deploys the latest standalone TALOS Social UI as a website.
It does NOT deploy the FastAPI backend or a persistent database.
Account creation, secure login, durable workspace data, and live LinkedIn publishing are NOT production-ready in this preview.

DEPLOY:
1. Extract this ZIP.
2. Go to vercel.com/new and create a new project using a Git repository containing index.html and vercel.json, OR use the Vercel CLI from this folder: npx vercel
3. Choose Framework Preset: Other. Root directory: this folder. No build command is needed.
4. Deploy, then open the generated vercel.app URL.

IMPORTANT: Treat this as a design/interaction preview, not a production SaaS launch. Do not enter real credentials or sensitive candidate information.
