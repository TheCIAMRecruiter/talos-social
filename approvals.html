Advanced · Legacy Make integration (optional)

Legacy Make integration

This optional legacy inbound integration is for advanced users only. Standard TALOS AI generation does not require it. Generate a private workspace integration token for Make. Creating a new token invalidates the previous one. Copy it immediately; TALOS does not store a readable copy.

Endpoint: https://mrgzxokmjxpsdlymxjtc.supabase.co/functions/v1/talos-make-ingest

In Make, add an HTTP POST after Claude. Use Authorization: Bearer [your token], Content-Type: application/json, and JSON fields workspace_id, external_id, topic, draft_text. Use a stable unique external_id for retries.
